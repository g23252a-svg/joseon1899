# 팔도천하 — 기획서

> 수치의 정본은 코드다(`js/core/rules.js`, `js/core/battle.js`, `js/data/*`). 이 문서는 설계 의도와 수식의 뼈대를 적는다.

## 1. 한 줄 소개

조선 팔도 32고을을 두고 여러 세력이 다투는 턴제 전략 게임. 장수를 부려 땅을 넓히는 **삼국지**, 문물과 위업을 쌓는 **문명**, 계층과 법령을 조율하는 **빅토리아**를 한 판에 엮었다.

### 설계 기둥

1. **장수가 주인공이다.** 모든 행동은 장수 한 명의 한 철을 쓴다. 능력치와 특기가 결과를 바꾼다.
2. **세 축이 서로 물린다.** 전쟁은 쌀과 민심을 먹고, 내정은 문물로 빨라지고, 문물은 법령을 열고, 법령은 세력 집단을 움직인다.
3. **결정은 보이게.** 출진 전에 모의 전투로 승률을, 명령 전에 효과 예상치를, 법령 옆에 집단별 반응을 보여 준다.
4. **번거로움은 위임으로.** 고을마다 위임·방침을 켜 두면 남은 장수가 알아서 일한다.

## 2. 시간과 지도

- 한 턴 = 한 철(봄·여름·가을·겨울). 쌀은 가을에 크게 거둔다(계절 배율 0.6/0.8/2.0/0.6).
- 지도는 경위도로 그린 해안선 위에 고을 씨앗 32개의 **보로노이 경계**를 구불구불하게 그린 것. 인접 관계는 공유 변이 땅 위를 지나는지로 계산하고, 동해안 길·압록강 길·제주 뱃길을 덧붙였다.
- 고을 속성: 인구(천 명), 농업·상업·성곽(상한은 건물로 오름), 민심, 병력, 훈련, 지형(평야·강·산지·해안·섬), 특산물, 교역 거점.

## 3. 자원과 수식

| 자원 | 들어오는 곳 | 나가는 곳 |
|---|---|---|
| 錢 | (상업×0.45 + 인구×0.5) × 세율 × 민심계수 × (1+보정) + 특산물 + 교역 | 명령, 건설, 녹봉(장수당 약 6+능력합/60), 군비(병사당 0.012) |
| 米 | (농업×2 + 인구×1) × 세율 × 민심계수 × 계절 × (1+보정) | 군량(병사당 0.06/철), 징병(0.15/명), 출진(0.1/명), 선정 |
| 學 | 고을(0.5+인구×0.012+건물), 지력 62 넘는 장수, 「연구」 명령 | 문물 비용 = 기본×3.6×(1+익힌 수×0.025) |
| 名 | 고을 수/4, 예술가, 위업, 승리, 사건 | 법령 변경(80), 사건 선택지 |

- 민심계수 = 0.45 + 민심/180. 민심은 매 철 목표치(세율·정통성·건물·특산물·세력 집단)로 다가간다.
- 쌀이 바닥나면 병력 −10%·민심 −5, 돈이 바닥나면 장수 충성 −3.
- 고을이 먹여 살릴 수 있는 병력(인구×300)을 넘으면 넘친 만큼 흩어진다.

## 4. 장수와 명령

능력치: 통솔·무력·지력·정치·매력. 특기 26종(기병·궁술·화포·수군·수성·의병·매복·계략·돌격·무예·인덕·내정·학문·발명·축성·외교·상재·의술·선동·승병·북방·예술·개혁·지리·선박·의적).

| 무리 | 명령 | 핵심 수식 |
|---|---|---|
| 내정 | 개간·상업 | +(6+정치×0.22) × 특기 |
| | 축성 | +(6+통솔×0.18) × 특기 × (1+거중기) |
| | 선정 | 민심 +(3+매력×0.07), 米 150 |
| | 연구 | +지력×0.22 × 특기 |
| | 건설·위업 | 고을당 한 번에 하나, 세력당 위업 하나 |
| 군사 | 징병 | (300+매력×10) × (1+법령·병영), 錢 0.06·米 0.15/명, 민심 하락 |
| | 훈련·이동·수송·출진·(임진년) 해전 | |
| 인사 | 탐색 → 재야 발견·즉석 설득, 보물, 숨은 인재 | 성공 0.35+지력/250+매력/300 |
| | 등용 | 재야: 0.42+(매력−50)/100… / 적 장수: (75−충성)/100… |
| 계략 | 유언비어(민심↓)·이간(충성↓)·선동(민심<40이면 민란) | 0.42+(지력−상대 지력)/150 |
| 외교 | 친선·동맹·휴전·항복 권고 | 관계·국력비·매력·외교 특기 |

장수 충성은 정통성·군주 매력·보물로 정해지는 목표치로 다가간다. 30 아래면 떠나거나 이웃으로 넘어간다.

## 5. 전투

- 한 판 최대 8일(해전 6일). 매일 양쪽이 작전을 고른다.
- 상성: **돌격 > 계략**, **수비 > 돌격**(역습 ×1.6), **계략 > 수비**(성공률 +25%). 사격은 무난하며 신기전·조총·궁술·화포의 덕을 본다.
- 계략 성공률 = 0.42 + (지력차)/110 + 특기·지형·기술, 최대 85%. 이름은 지형에 따라 매복·화공·수공·기습.
- 피해 = 병력 × 질 × 0.05 × 작전배율. 질 = (0.55+통솔/200+무력/400)×(0.6+훈련/250)×(1+기술)×(0.6+사기/250).
- 공성: 수비측이 받는 피해 ÷ (1+성곽/600). 공격측은 매일 병력×0.008만큼 성벽을 깎는다.
- 사기: 잃은 병력 비율×110만큼 깎인다. 0이 되거나 병력이 4% 아래면 무너진다. 8일을 버티면 수비측 승리.
- **일기토**: 베기 > 내려치기 > 막기 > 베기, 기합으로 기를 모아 필살. 이기면 사기 +20/−30, 진 장수는 부상(가끔 전사). 상대는 거절할 수 있다(사기 −12).
- 이기면 고을과 포로. 포로는 등용(확률)·석방(名 +5, 관계 +8)·처형(名 −10~25).
- AI 와 플레이어 출진 창은 같은 엔진으로 **모의 전투**를 돌려 승률을 계산한다.

## 6. 문물과 위업

4시대 31개: 창업(농사직설·훈민정음·자격루·의방유취·측우기·갑인자·신기전·4군6진·경국대전) → 수성(판옥선·비격진천뢰·거북선·조총·훈련도감·대동법·동의보감·상평통보) → 중흥(균역법·탕평책·실학·거중기·대동여지도·서학) → 개화(개항·전신·증기선·신식 군대·근대 학교·철도·갑오개혁·광무개혁).

위업 8개(천하에 하나): 경복궁·종묘·집현전·팔만대장경판전·성균관·남한산성·수원 화성·독립문. 먼저 끝낸 세력만 갖고, 늦은 쪽은 절반을 돌려받는다.

## 7. 정치

- 세력 집단: 사림·훈척·무반·상인·농민·개화파(개항 뒤). 영향력(%)은 법령·기술로, 지지(−100~100)는 법령·세율·형편(전쟁 승패, 징병, 민심, 교역)으로 정해지는 목표치로 매 철 25%씩 다가간다.
- 지지 ≥30: 혜택(學·錢·米·훈련·정통성). 지지 ≤−30: 상소·반정·군란·철시·민란·정변 사건.
- 법령 7범주 × 3안: 조세·군역·신분·학문·상업·대외·왕권. 바꿀 때 名 80(개혁 특기 −30%).
- 세율 4단계(×0.8 ~ ×1.5): 수입과 민심·농민·상인 지지를 맞바꾼다.
- 정통성: 도읍 한성, 군주 매력, 위업·기술, 훈척 지지로 오른다. 장수 충성과 민심 목표치에 들어간다.

## 8. 사건

철마다 55% 확률로 1~2개. 계절·조건·세력 상태를 본다. 꼭 일어나는 것: 식년시(3년마다 봄 — 문과·무과·잡과로 인재), 양요(이양선을 포격한 뒤). 일기토로 푸는 사건: 화적 두령, 호랑이(산군).

## 9. 컴퓨터 세력

연구(성향 가중) → 세율·법령 → 고을 방침 → 보물 하사·포상·재야 등용 → 외교(휴전·동맹·플레이어에게 귀순 제의) → 출진(후보 두 곳을 모의 전투로 확인, 성향별 요구 승률 0.40~0.72) → 병력·장수 전방 배치 → 건설·위업 → 남은 장수 위임.
플레이어에게는 첫 한 해 공격하지 않고, 두 해째까지 조금 너그럽다(임진년 제외).

## 11. 임진년 특수 규칙

- 조선 살림은 전란으로 60%에서 시작해 해마다 12%씩 회복.
- 왜군 증원(턴별 표)과 바닷길 군량은 **제해권**만큼 줄어든다. 조선 수군 장수가 남해·서해 바닷가 고을에서 「해전」으로 왜 수군을 치면 제해권이 오른다.
- 의병장(곽재우·고경명·조헌·김천일·김면·휴정·유정·정문부·김덕령)이 차례로 일어나 병력을 데리고 합류한다.
- 명 원군(이여송·송응창·낙상지, 정유년에 마귀·진린·등자룡)은 군사 명령만 따르는 「원군 장수」로 합류.
- 1593년 강화 교섭(받으면 3년 휴전) → 1597년 정유재란(대규모 재상륙) → 1598년 가을 히데요시 사망(왜군 병력 −30%).
- 왜군 점령지의 민심이 바닥나면 의병이 일어나 조선 땅으로 돌아온다.

## 12. 고증과 각색

- 「팔도군웅전」은 시대가 다른 인물이 함께 나오는 가상 시나리오다.
- 「임진년」의 날짜·인물·사건은 실제를 바탕으로 게임에 맞게 줄이고 각색했다(예: 턴 단위 사건 시점, 명군의 지휘 방식).
- 능력치는 게임을 위한 평가이며 인물에 대한 사실 판단이 아니다. 일본·명 인물도 같은 기준으로 다룬다.
