# 팔도천하 八道天下 — 조선 군웅 전략

조선 팔도를 무대로 한 턴제 전략 게임. 브라우저에서 바로 돈다(설치·빌드 없음).

- **삼국지(코에이)식**: 장수 120명(능력치 5종·특기·충성·보물), 장수마다 한 철 한 번 명령, 출진·공성·일기토, 포로 등용·석방·처형, 재야 인재 탐색
- **문명식**: 4시대 31개 문물(기술) 나무, 위업 8개(경복궁·팔만대장경판전·수원 화성…), 천하통일·태평성대(문화)·근대화 승리
- **빅토리아식**: 세력 집단 6개(사림·훈척·무반·상인·농민·개화파)의 지지·영향력, 법령 7범주(대동법·균역법·신해통공·개항…), 세율, 민란
- **그 밖에**: 사건 30여 개(가뭄·역병·과거 시험·암행어사·호랑이 퇴치 일기토·이양선·동학…), 외교(동맹·휴전·항복 권고·혼인), 특산물 교역, 해전과 제해권

그림과 소리는 모두 코드로 만든다(수묵채색 지도, 절차 생성 초상화, WebAudio 효과음). 이미지·사운드 파일이 없다.

## 시나리오

| 시나리오 | 내용 |
|---|---|
| **팔도군웅전** (가상) | 세종·이성계·이순신·정조·곽재우·홍경래·임꺽정·이이·전봉준이 시대를 넘어 팔도에 할거한다. 고을 32곳 중 다수는 주인이 없다. |
| **임진년** (역사 각색) | 1592년 4월 왜군 상륙부터 1598년 겨울까지. 조선(또는 왜군)을 맡는다. 의병 봉기, 명 원군, 강화 교섭, 정유재란, 제해권이 왜군 증원·군량을 좌우한다. |

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 정적 서버로 띄운다.

```bash
# 저장소 루트에서
node tools/devserver.cjs . 5173
# → http://localhost:5173/paldo/index.html
```

## 조작

- 지도: 끌어서 이동, 휠·두 손가락으로 확대, 고을을 눌러 고을 판 열기
- 고을 판: 장수를 눌러 명령, 「출진」으로 이웃 고을 공격(모의 전투 16번으로 예상 승률 표시)
- 단축키: `Enter` 철 넘기기 · `Esc` 창 닫기 · `T` 문물 · `P` 정치 · `O` 인물 · `D` 외교 · `F` 형세 · `L` 실록
- 저장: 3칸 + 해마다 봄 자동 저장. 브라우저 저장소를 못 쓰는 곳에서는 「저장 문자열」로 백업한다.

## 시험

```bash
cd paldo
node tools/sim.mjs --scenario=allstar --turns=240 --seed=1   # 규칙 전체를 AI끼리 돌리며 불변식 검사
node tools/sim.mjs --scenario=imjin --turns=40 --seed=2
node tools/browser.mjs --turns=6                             # 실제 화면(Playwright) — 스크린숏은 /tmp/paldo-shots
node tools/browser.mjs --turns=4 --mobile --scenario=1
```

## 구조

```
paldo/
  index.html            페이지 뼈대와 스타일
  js/main.js            부팅
  js/core/              규칙(DOM 없음 — Node 에서도 돈다)
    state.js            상태 만들기·조회·소유 변경        rules.js     경제·연구·정치 수식
    actions.js          장수 명령·출진·위임               battle.js    전투·일기토·포로
    ai.js               컴퓨터 세력                       war.js       전투 진행 묶음
    turn.js             철 넘기기 순서·임진년 규칙         victory.js   승패
    diplomacy.js        외교                              geo.js       해안선·보로노이 경계·인접
  js/data/              고을·인물·문물·법령·건물·사건·시나리오
  js/ui/                지도·고을 판·전투 화면·각종 창·타이틀
  tools/                sim.mjs(헤드리스) · browser.mjs(Playwright)
  docs/GDD.md           기획과 수식
```

인물 능력치는 게임을 위한 평가이며, 「팔도군웅전」의 설정은 가상이다.
